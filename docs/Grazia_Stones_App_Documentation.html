2. Project Overview

Grazia Stones AI Smart Estimator is a mobile + web application that lets a customer point their phone at a real wall, see a chosen tile/stone design projected onto it in real time using AR, measure the wall directly from the camera, get an automatic tile quantity and cost estimate, and place an order or request a quote — all inside one app. It also includes an AI-based "upload a room photo" mode for customers who don't want to use live AR, plus a catalogue, cart/checkout, dealer & lead management, and an admin panel to manage products centrally.

3. Complete App Flow

3.1 First-Time Journey

  1. Splash — brand animation, initializes local storage and connects to backend in the background.
  2. Onboarding — introduces the core value: point your phone at a wall, see the design live.
  3. Login / Register / Guest — email+password or phone OTP; guest browsing supported for the catalogue.
  4. Home — featured collections, trending stones, quick entry into Live AR.

3.2 Core Flow — Live AR Visualization

StepWhat Happens
Open Live ARCamera permission requested contextually (only here, not at app launch). Native ARKit/ARCore session starts.
Point at wallApp detects vertical wall planes in real time and shows a subtle detection indicator.
Wall lockedOnce tracked with confidence, status changes from "Searching" to "Wall detected" — with haptic feedback.
Select tile/stoneSwipe through the product carousel — material projects onto the real wall instantly, no AR restart.
Switch colour/variantTap a colour swatch — texture updates on the wall live, tracking is not interrupted.
Move the phoneThe wall anchor stays spatially fixed — perspective changes naturally as you move.
Measure wallTap two points on the wall (real ARKit world anchors, not screen pixels) for width, then two more for height.
Auto tile quantityApp calculates tiles needed, wastage %, and estimated cost from the measured wall area and tile size.
Capture / ShareSave or share the visualization and the estimate.

3.3 AI Room Photo Mode (no live AR needed)

  1. Upload or take a photo of the room.
  2. Select tile/stone + colour + finish.
  3. Backend detects the wall, segments obstacles (furniture, windows, doors), applies the material only to the wall.
  4. Result preserves the room's real furniture and lighting.

3.4 Catalogue → Order Flow

  1. Collections / Search — browse by category, filter, search.
  2. Stone Detail — full specs, price, gallery, "Try in AR" shortcut.
  3. Cart — add tiles/stones with quantity.
  4. Checkout — address, Razorpay payment, order confirmation.
  5. Orders — track order status.
  6. Sample Order / Quote Request — request a physical sample or a formal PDF quotation instead of buying directly.
